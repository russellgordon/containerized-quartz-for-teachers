## Three things worth knowing

1. **Links go both ways.** At the bottom of every page is a **Backlinks** list
   showing which pages link *to* it. Landing on [[Ohm's Law]] shows you every
   class and lab that used it.
2. **Hover to peek.** Hovering a link previews the page without leaving this one.
3. **Search is fast.** Press <kbd>Ctrl</kbd> + <kbd>K</kbd> (or
   <kbd>⌘</kbd> + <kbd>K</kbd>) and start typing.

> [!tip] The most useful habit
> When you are lost in a class page, follow the link to the concept. When you
> are lost in a concept, use backlinks to find the class where we did it. The
> two directions get you unstuck fast.
