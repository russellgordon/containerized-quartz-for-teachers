## Agenda

1. Warm-up: [[Which One Doesn't Belong]] — four ways for a program to
   wait
2. Bench: make your controller do two jobs at once using delays. Watch
   it miss a button press, then measure exactly how many milliseconds
   it was deaf for
3. Name it: [[State Machines]] — states, events, transitions, and a
   loop that never blocks
4. Rewrite the sketch properly: [[State Machines in Code]], with the
   diagram drawn on paper before a line is typed
5. Practise: [[State Machine Practice]]

## Things to do before our next class

- [ ] Draw the state diagram for your control system, including the
      state it enters when a sensor stops answering.
- [ ] Journal: the longest your old code could ignore the world, in
      milliseconds, and what that would mean for a moving machine.
