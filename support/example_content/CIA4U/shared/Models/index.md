A model is a way of reasoning, not a fact about the world. Each of these
is a small machine you build on purpose, so that you can hold most of the
economy still and think about one part of it. Every page says what its
model holds still — which is also where it stops being trustworthy.

`Models` and `Data` are separate folders for a reason: a student who
confuses them argues from a curve instead of from the economy.
