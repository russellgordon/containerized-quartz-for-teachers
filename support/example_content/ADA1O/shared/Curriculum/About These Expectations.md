Each page keeps the expectation's official **code** — `A2.2`, `C3.1`, and
so on — and every lesson, task, and discussion in this course links back
to the codes it addresses. The codes are also tags, so every page tagged
`#A2` can be gathered in one place.

## Why the codes matter more than they look

A code is a shared address. When a student asks "why are we doing this?",
the answer is a link. When a department writes a course outline, or a
teacher takes over a class partway through, the codes are what make one
person's planning legible to another.

## How this course reads them

The overall expectations (`A1`, `B2`, …) name what the course is for; the
specific expectations (`A1.1`, `B2.3`, …) name what we practise week to
week. The folded note on each specific expectation's page holds the
Ministry's own discussion prompts — useful when planning, and a window
into what the expectation looks like in a classroom.
