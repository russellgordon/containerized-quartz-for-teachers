Rehearsal is three verbs: **deciding, trying, and keeping**. Decide what a
moment needs, try a way of getting it, keep what worked. A group cycling
through those three is rehearsing; a group merely together in a room with
a scene is doing something else, usually chatting.

This is [[The Creative Process|the creative process]] at working speed:
explore, experiment, revise — except now the clock is running and the
performance date is real.

## Running a scene versus working a scene

- **Running** means going start to finish without stopping, no matter what
  goes wrong. It builds stamina and it is the only way to learn whether
  the whole thing hangs together.
- **Working** means stopping at the hard part — the transition that keeps
  collapsing, the moment nobody believes — and trying it three different
  ways before choosing one.

Weak rehearsals run everything and work nothing — the same problems
survive every pass. Strong rehearsals run once to find the weakest moment,
work that moment properly, then run again to see whether the fix holds.

> [!tip] Say the decision out loud
> "Keeping" only happens if someone names it: "So we are keeping the slow
> start — agreed?" A choice nobody says aloud is a choice the group will
> quietly forget by Thursday. One person writing decisions down turns a
> good rehearsal into a permanent one.

## Protecting the time

Class rehearsal time looks long and is not, and it only counts if everyone
arrives warmed, on time, and still holding last class's decisions — that
is the job. Three habits protect the minutes:

- **Start standing.** The first two minutes on your feet, not settled
  around a table deciding to begin.
- **One problem per session.** Name the weakest moment at the start; fix
  only that, and the rehearsal succeeded.
- **End with a run.** The last minutes belong to a clean pass, so everyone
  leaves holding the same scene.
