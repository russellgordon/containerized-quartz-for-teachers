A case is an organization with a problem, described in enough detail to
argue about. We work them in class with a pen, and then again in review,
because a case you have already met tests something different the second
time.

If this is your first one, read [[Reading a Business Case]] first — there
is a method, and it takes twenty minutes to learn.
