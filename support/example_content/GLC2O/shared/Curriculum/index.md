Everything this course does points at one or more of these expectations,
from **GLC2O — Career Studies, Grade 10, Open**, the version effective September 2024.

This is a **half-credit course**: 55 hours, taken in the same semester as
its partner course rather than spread across a full one.

> [!info] Where these come from
> The wording below is the Ontario curriculum's own. See
> [[About These Expectations]] — including which version this is, which
> matters for both of these courses.
