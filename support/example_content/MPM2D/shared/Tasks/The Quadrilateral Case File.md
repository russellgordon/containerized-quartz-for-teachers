> [!abstract] At a glance
> Groups of three · three working periods in Week 8 · verdicts filed at
> the end of that week · one case file per group

## What you are making

Your group receives four vertices — nothing else. Somewhere in those
eight coordinates is the true identity of a quadrilateral, and your job
is to establish it beyond reasonable doubt. Is it merely a
parallelogram, or secretly a rhombus? Every claim in your verdict
must be backed by evidence: a slope, a length, or a midpoint.

You finish with a **case file**: the accusation (your first
conjecture), the evidence, the verdict, and an honest closing titled
*what would change our verdict*. [[What Makes a Proof Convincing]] is
the standard the file is judged against.

## How to work

1. Plot the four points and make an accusation. "It looks like a
   rectangle" is a fine place to start — and worthless as a place to
   finish.
2. Decide what evidence the verdict needs. [[Properties on the Grid]]
   lists what each quadrilateral must prove about itself: parallel
   sides want slopes, congruent sides want lengths, bisecting
   diagonals want midpoints.
3. Gather the evidence with the tools from [[Midpoint and Length]].
   Label every calculation with the claim it supports — a bare number
   in a case file is inadmissible.
4. Rule stronger verdicts in or out. Parallelogram is only the floor;
   check whether right angles or equal sides promote it. Diagonals can
   convict where sides are inconvenient — strong files use both routes.
5. Write *what would change our verdict*: name the one measurement
   that, had it come out differently, would have demoted your square
   to a rhombus — and say how confident you are in that measurement.
6. File the case.

The working periods are class time, and using them well is part of the
task — [[How Marks Work]] explains how.

## Success criteria

| Quality | What it looks like in your case file |
| --- | --- |
| An exact verdict | The most specific name the evidence supports |
| Evidence for every claim | No property is asserted without a calculation |
| Stronger claims tested | Promotions were checked, never assumed |
| Labelled calculations | Each computation states what it proves |
| An honest closing | The file names what would overturn it |
| A readable argument | The reasoning holds without the authors present |

## Reflect

Each member writes a short journal entry: which piece of evidence
settled the case for you, and which claim were you most tempted to
accept from the picture alone? That gap is what this task is about.

> [!success]- If your quadrilateral seems to be nothing special
> "No special name" is itself a verdict — and it needs evidence too.
> Show which properties fail, not just which ones you could not find.
