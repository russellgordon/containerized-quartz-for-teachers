Four equations, four corners, and one question: which one doesn't
belong? The trick is that there is no trick — every corner can be
defended, so the game is never about *the* answer. It is about
naming, precisely, the property your corner alone possesses.

|  |  |
| --- | --- |
| **A** — $y = x^2 + 1$ | **B** — $y = -(x-2)^2$ |
| **C** — $y = 2(x+3)^2 + 1$ | **D** — $y = (x-2)^2 - 4$ |

> [!example]- A defence for every corner (click to expand)
> - **A** — the only parabola whose vertex sits on the $y$-axis; no
>   horizontal slide at all.
> - **B** — the only one that opens downward, and the only one with
>   exactly one zero, since its vertex rests on the $x$-axis.
> - **C** — the only one narrower than $y = x^2$, and the only vertex
>   left of the $y$-axis.
> - **D** — the only one with two zeros: it opens up from below the
>   $x$-axis, so it must cross twice.

## One variation

Four *graphs* with no equations at all — then the defences must lean
entirely on the language of [[Transformations of Parabolas]]. Or run
it in reverse: the class builds a fourth equation so that a chosen
corner becomes defensible.

> [!tip] "It looks different" scores nothing
> Precision is the whole game. Not "C is weird" but "C is the only
> one with a vertical stretch". Naming $a$, $h$, and $k$ correctly
> here is exactly the skill [[The Vertex Form]] runs on.
