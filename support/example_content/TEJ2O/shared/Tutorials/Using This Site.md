This site is the course's memory — every class, concept, lab, and
practice set lives here. Five habits make it fast to use.

## The five habits

1. **Land on today.** The home page always surfaces the most recent
   class, so "what did we do?" and "what is due?" are one click from
   anywhere. Absent? Start there before asking anyone.
2. **Search first.** Press `Cmd + K` on a Mac or `Ctrl + K` on
   Windows and type any word — "static", "crimp", "voltage". Search
   reads every page at once; it is nearly always faster than
   navigating.
3. **Hover before you click.** Rest your pointer on any
   [[Electronics Fundamentals|link like this one]] and a preview of
   the target page pops up. You can often confirm a definition
   without leaving the lab instructions you are in the middle of.
4. **Read the backlinks.** At the bottom of each page, *Backlinks*
   lists every page that links **to** this one. On a concept page,
   that is an instant map of every lab where the idea does work —
   the site's web, walked backwards.
5. **Predict before you unfold.** Practice pages in Exercises fold
   their answers away — click the callout and it expands. The fold
   is a tool, not a lock: commit to your own answer first, then open
   it. Peeking first feels efficient and teaches nothing.
