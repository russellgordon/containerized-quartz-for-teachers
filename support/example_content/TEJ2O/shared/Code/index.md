Why does a hardware course write software? Because every machine
in this room is half metal and half instructions, and a technician
who reads only one half is doing half the job. The curriculum
agrees — programming is [[B5.1|a strand of its own]] — so this
folder teaches just enough Python to make hardware ideas testable
in ten honest lines.

| Page | What it covers |
| --- | --- |
| [[First Programs]] | Print, input, variables — predicting first |
| [[Decisions and Loops]] | Programs that choose and repeat |
| [[Code Meets Hardware]] | How software drives the physical world |
| [[Debugging Basics]] | Bench diagnosis, applied to code |

Nothing needs installing: any online Python interpreter runs it
all. Keep one open in a tab beside the page and type each program
in yourself — typing is reading with witnesses.
