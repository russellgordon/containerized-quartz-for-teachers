Five minutes at the start of class, every class. None of these
routines needs a powered-up bench, and none of them is filler — each
one keeps a habit warm that the shop will later demand under
pressure: precise names, reasoning defended out loud, an eye that
catches what is wrong before it gets expensive.

| Warm-up | What it trains |
| --- | --- |
| [[Name That Part]] | Naming components and their jobs on sight |
| [[Binary Bites]] | Moving between number systems, method defended |
| [[Spot the Hazard]] | Seeing an unsafe bench before touching it |
| [[Which One Doesn't Belong]] | Hardware vocabulary, argued out loud |
| [[Tech Headlines]] | Weighing claims made about technology |
| [[Predict the Circuit]] | Reading a schematic closely enough to commit |

None of these is ever a race. When a routine starts to feel easy,
that is not a cue to speed up — it is the sign a habit has moved in
for good. Help the bench beside you get there too.
