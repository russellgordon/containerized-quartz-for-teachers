Four things go up in a two-by-two grid — parts, ports, cables,
connectors, drives — and the question never changes: which one
doesn't belong? There is no answer key. Every corner can be
defended, and the defence is the point: arguing out loud demands
the precise vocabulary that pointing and saying "that one" skips.

## How to run it

1. Show the grid. One quiet minute — everyone commits to a corner.
2. Hands up by corner. A good grid gets takers in all four.
3. Defenders speak. The rule: name the *property*, not the vibe —
   "only one carries power as well as data" beats "it looks old".
4. Close by collecting the vocabulary the defences used.

> [!example]- A grid to start with (click to expand)
> | | |
> | --- | --- |
> | USB-C port | Ethernet port |
> | HDMI port | headphone jack |
>
> Only one is analogue. Only one talks to a network. Only one is
> mainly for video. Only one can charge its machine. Four honest
> corners — and vocabulary straight from [[Peripherals and Ports]].

## One variation

Students build the grids, pulling from the parts bin or their own
[[Take It Apart]] photos. A grid with four honest corners is
harder to build than to solve — which is why building one pays more.

> [!tip] Take up a corner you did not pick
> Once your own corner is safe, defend a different one — the
> vocabulary is only owned when you can argue all four.
