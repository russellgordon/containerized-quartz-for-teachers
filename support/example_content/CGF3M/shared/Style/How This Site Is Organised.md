The sidebar is the whole course. Each folder holds one kind of page, and
knowing which kind you want is faster than searching.

| Folder | Holds | Read it |
| --- | --- | --- |
| All Classes | One page per period: agenda, links, what to do next | Every day |
| Concepts | The ideas, one to a page | After the class that uncovered it |
| Mapping | How to read and make maps | Before a mapping task |
| Sources | Where data lives and how to judge it | Whenever you cite anything |
| Fieldwork | What happens on a field day | Before and after each one |
| Case Studies | Real events, worked with sourced figures | When a unit reaches them |
| Discussions | Seminar questions and how to prepare | Before the seminar |
| Portfolios | Work you collect across the whole term | Continuously |
| Tasks | Everything you are marked on | At launch, and again before the due date |
| Tutorials | How to use the site and the inquiry process | Week one |
| Setup | How the class runs | Week one, and when something is unclear |
| Style | How the site itself works | Once, out of curiosity |

## Why it is arranged this way

The **schedule is the spine**. Everything you need on a given day is
linked from that day's class page, so if you follow All Classes you will
never need to hunt. The other folders exist so that an idea has one home
and can be linked from every class that uses it, rather than being
retyped into six agendas.

That is also why Concepts and Case Studies are separate. A concept is a
way of reasoning that transfers; a case is one real event with real
figures that must be attributed. Confusing the two produces writing that
argues from an anecdote and calls it a principle.

## How pages connect

Pages link forward to what you will do with an idea and back to what it
rests on. At the foot of most pages you will find the backlinks — every
page that points here — which is the quickest way to see where an idea
was actually used.

Nothing here is a textbook chapter to be read ahead. The pages assume you
have already met the idea in a class, and they state it cleanly so you
can use it.
