Why does a mathematics course ask you to write code? Two honest
reasons. First, the curriculum says so — see
[[C2.1|the coding expectations]]. Second, and better: code makes
mathematical relationships *dynamic*. On paper, a formula just sits
there; in code, you change one number and watch an entire pattern,
bill, or experiment respond instantly. That is a kind of seeing
paper cannot offer.

You need nothing special to run the Python on these pages — an
online Python interpreter in any browser works fine, and so does
whatever your school provides. The routine never changes: read the
code, *predict* what it will print, run it, and compare. Being
wrong in a prediction costs nothing and teaches plenty — that is
[[Mistakes Are Data]] in its purest form.
