Most days, the first ten minutes of class are a number talk: one prompt
on the board, no pencils, no calculators. You think, then defend your
reasoning aloud while we listen for paths unlike our own. There is no
single right method — the point is number sense, and the courage to
reason in public. Every talk below runs on that same rhythm.

| Talk | What it trains |
| --- | --- |
| [[Dot Talks]] | Seeing structure before counting |
| [[Estimation Duels]] | Judging whether an answer is reasonable |
| [[Which One Doesn't Belong]] | Naming properties precisely |
| [[Visual Patterns]] | Seeing the general in the specific |
| [[Number Strings]] | Letting one problem unlock the next |
| [[True or False]] | Treating equality as a claim to test |
| [[Fraction Talks]] | Seeing parts of a whole in many ways |
| [[Would You Rather]] | Backing a choice with mathematics |
