These questions follow [[Solving Equations]] — the balance reasoning
was built in class through [[True or False]]. Every answer here ends
with a *verification*: an unchecked solution is a guess with confidence.

## Questions

1. Solve $x + 7 = 15$, and verify your solution.
2. Solve $3n - 5 = 16$, and verify.
3. Solve $2(x + 4) = 22$.
4. Solve $5x - 3 = 2x + 9$.
5. **Create, then solve.** A phone plan costs \$15 plus \$2 per
   gigabyte. One month's bill is \$27. Write an equation for the
   data used, solve it, and check it against the story — this is the
   maths behind [[Which Phone Plan]].
6. **Find the error.** Solving $4x + 2 = 18$, Omar gets $x = 5$.
   Verify Omar's answer, explain what the check reveals, and find the
   correct solution.
7. Solve $\frac{x}{3} + 2 = 7$.
8. **Challenge.** Create an equation with variables on *both* sides
   whose solution is $x = -4$, and prove your equation works.

## Answers

> [!success]- Answer 1
> Subtract 7 from both sides: $x = 8$. Verify: $8 + 7 = 15$. ✓

> [!success]- Answer 2
> Add 5, then divide by 3: $3n = 21$, so $n = 7$. Verify:
> $3(7) - 5 = 21 - 5 = 16$. ✓

> [!success]- Answer 3
> Divide both sides by 2 first: $x + 4 = 11$, so $x = 7$. Verify:
> $2(7 + 4) = 22$. ✓ Expanding first also works — same destination.

> [!success]- Answer 4
> Subtract $2x$: $3x - 3 = 9$. Add 3, divide by 3: $x = 4$. Verify
> both sides separately: $5(4) - 3 = 17$ and $2(4) + 9 = 17$. ✓

> [!success]- Answer 5
> Let $g$ be gigabytes used: $15 + 2g = 27$, so $2g = 12$ and
> $g = 6$. Check the story: \$15 plus $6 \times \textdollar 2$ is \$27. ✓
> The equation is the story, compressed.

> [!success]- Answer 6
> Check $x = 5$: $4(5) + 2 = 22 \neq 18$ — the check fails, which is
> exactly what it is for. Omar likely *added* 2 instead of subtracting.
> Correctly: $4x = 16$, so $x = 4$, and $4(4) + 2 = 18$. ✓

> [!success]- Answer 7
> Subtract 2: $\frac{x}{3} = 5$. Multiply by 3: $x = 15$. Verify:
> $\frac{15}{3} + 2 = 5 + 2 = 7$. ✓

> [!success]- Answer 8
> Answers vary. One route: start from $x = -4$ and *build outward*
> by doing the same thing to both sides until it looks interesting,
> e.g. $3x + 2 = x - 6$. Prove it: $3(-4) + 2 = -10$ and
> $-4 - 6 = -10$. ✓ Equation-building is solving, run in reverse.
