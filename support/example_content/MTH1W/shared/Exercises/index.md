Practice in this course comes *after* sense-making, never instead of it.
Each set below follows a concept page — build the idea first, then use
the exercises to make it dependable. Attempt every question before
peeking: the answers sit in folded callouts precisely so a stray glance
cannot spoil the struggle, and the struggle is where the learning is —
see [[Why Struggle Is the Point]]. When you do expand an answer, you
will find worked reasoning, not a bare number. Compare *methods*, not
just results — a different route to the same answer is worth noticing.
None of these sets are timed. Ever.
