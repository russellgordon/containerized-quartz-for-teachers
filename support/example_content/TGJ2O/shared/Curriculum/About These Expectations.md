Each page keeps the expectation's official **code** — `A1.3`, `B2.4`,
and so on, exactly as the 2009 document prints them — and every story,
studio session, and task in this course links back to the codes it
addresses. The codes are also tags, so every page tagged `#B3` can be
gathered in one place.

## Why the codes matter more than they look

A code is a shared address. When a student asks "why are we doing
this?", the answer is a link. When a department writes a course
outline, or a teacher takes over a class partway through, the codes are
what make one person's planning legible to another.
