Pages about the site itself — how it is arranged, what it can do, and
how to write for it.

- [[How This Site Is Organised]] — the folders, and why the links
  between them matter more than the folders do.
- [[What This Site Can Do]] — every feature a page can use, with the

- [[Writing About Technology]] — measurements, symptom reports, and

If you used the Grade 10 site, all three names are familiar and the
site works the same way. The one page that has genuinely changed is
[[Writing About Technology]], because the standard has: this year a
claim needs a measurement, and a measurement needs units and
conditions.
