Some skills in this course are not concepts and not labs — they are
*ways of working at a bench*. Driving an instrument without destroying
it. Making a joint that survives being dropped. Finding a limit in a
datasheet instead of guessing at one. Each tutorial below teaches one
of those skills properly, once, so that every lab page can link here
instead of re-explaining it in a hurry while you are holding something
hot.

| Tutorial | The skill |
| --- | --- |
| [[Using This Site]] | Finding your way around this site quickly |
| [[Using a Multimeter]] | The instrument you will touch every single day |
| [[Using an Oscilloscope]] | Seeing what a voltage does over time |
| [[Soldering Safely]] | Joints that hold, fumes that go somewhere else |
| [[Reading a Datasheet]] | Finding the number instead of guessing it |
| [[Anti-Static Habits]] | Keeping invisible sparks off the hardware |
| [[Getting Unstuck]] | Being stuck well instead of spinning |
| [[Documenting Your Build]] | A record somebody else could work from |

Skim them all in the first week, then return to each one the moment it
becomes urgent. Two of them are urgent almost immediately:
[[Using a Multimeter]] earns its keep the first time you are asked for
a number instead of a description, and [[Soldering Safely]] earns its
keep before the iron is switched on rather than after.

If you took the Grade 10 course, three of these names are familiar and
one is nearly so — [[Reading a Datasheet]] is what
"reading a spec sheet" grows into once the document is written for
engineers rather than for shoppers. The rest are new, because the
instruments are new.
