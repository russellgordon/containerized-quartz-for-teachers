## Agenda

1. Warm-up: [[Predict the Circuit]] — an LED and a resistor on a
   $3.3\ \text{V}$ rail, current predicted in milliamps
2. Bench time: [[Blink, Read, React]] begins with the output half. The
   resistor gets sized before the LED is connected, and the pin's
   current limit gets read out of the datasheet before either
3. Read it, run it, then change it: [[Your First Embedded Program]] —
   short enough that every line is yours to be responsible for
4. Compare: whose blink was closest to the period they claimed, and how
   did they check?
5. Practise: [[Microcontroller Code Practice]], first block together
