## Agenda

1. Warm-up: [[Name That Part]] — the transistor round, packages and
   pinouts, no datasheet allowed for the first minute
2. Swap benches and read somebody else's program out loud. Every place
   you stopped and guessed is a place the structure failed. Mark them
3. Compare and name it: [[Structuring Embedded Code]] — functions,
   named constants, and pin numbers that belong in one place only
4. Launch: [[The Embedded Device]] — one sensor in, one actuator out,
   one job, and a claim that survives measurement
5. Tools away, log it in your [[Tech Journal]]
