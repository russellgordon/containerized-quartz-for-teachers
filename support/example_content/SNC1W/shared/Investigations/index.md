Every lab in this course. Each page has the same shape:

**Purpose → Safety → Materials → Procedure → Data → Analysis → Hand in**

Read the whole page **before** the class it belongs to. The safety section is
not optional reading.

> [!danger] Before every investigation
> Goggles, tied-back hair, closed-toe shoes. If you are missing any of the
> three, you will be doing the written alternative instead.

Format for the write-up: [[Writing a Lab Report]].
