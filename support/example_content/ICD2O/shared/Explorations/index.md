These activities come first — before the technique has a name, and
often before a computer is switched on. You will make sandwiches
badly, tear apart old machines, and pass string around the room, and
only afterwards learn what the ideas you invented are called. That
order is deliberate: an idea you needed is an idea you keep.

| Exploration | The question, roughly |
| --- | --- |
| [[The Sandwich Robot]] | Can your instructions survive a robot? |
| [[Algorithm Hunt]] | How many algorithms did you run today? |
| [[Inside the Box]] | What is all that stuff inside a computer? |
| [[The Phishing Gallery]] | Which of these messages wants to hurt you? |
| [[Talk to the Machine]] | What is an AI chatbot actually good at? |
| [[Build a Network]] | Can string and index cards carry a message? |

None of these pages ends with an answer — on purpose. The ideas get
built the way they were built the first time: together, by needing
them.
