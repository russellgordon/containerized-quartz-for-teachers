This site is the course: the schedule, the ideas, the data, the field
days, and the expectations behind all of it.

| Folder | Holds | You will use it |
| --- | --- | --- |
| **All Classes** | One page per period — the agenda and what to do next | Every day |
| **Concepts** | The ideas, stated cleanly | After the class that uncovered one |
| **Mapping** | How to read and make maps, and use a web GIS | Whenever a task needs a map |
| **Sources** | The datasets and documents this course uses | Whenever you need real numbers |
| **Fieldwork** | The shoreline, woodlot, farm, and street visits | Before and after each field day |
| **Issues** | Real Canadian issues, worked as cases | In class, and again in review |
| **Discussions** | Seminar questions and how to prepare | The night before a seminar |
| **Portfolios** | Your four portfolio entries | Across the whole term |
| **Tasks** | Assessed work, with what earns the marks | Whenever something is due |
| **Tutorials** | How to run an inquiry, cite, and use this site | The first time you need one |
| **Setup** | How the class runs | Week one |
| **Style** | How the site works | Now |

## How the pieces connect

Class pages are the spine — each links to what that period actually
consists of. The backlinks at the bottom of any page show you which
classes used it, which is the fastest way to find where an idea came up.

Content pages end with a **Curriculum connection**: the Ministry
expectations that page addresses, in the Ministry's own words. The site
also builds a coverage map from those links, so you can see what the
course has actually taught.

## Two conventions

- **Concept pages come after the doing**, not before. They assume you
  have already met the idea.
- **The newest class is on the section landing page.** If you were away,
  start there.
