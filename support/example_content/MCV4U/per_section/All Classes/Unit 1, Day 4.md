## Agenda

1. Number talk: [[Which One Doesn't Belong]] — four sequences, each
   heading somewhere (or refusing to)
2. Random groups: march $n$ upward through
   $\left(1 + \frac{1}{n}\right)^n$ — the values creep higher; do they
   creep forever?
3. Consolidate: [[The Limit]] — a name for the value a march settles
   toward without ever needing to arrive
4. Practise: [[Limits Practice]], first set
5. That number your marches crept toward, a little past $2.718$ —
   remember it; it returns in Unit 2
