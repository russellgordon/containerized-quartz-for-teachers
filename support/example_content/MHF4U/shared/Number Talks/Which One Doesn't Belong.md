Four functions, four corners, and one question: which one doesn't
belong? The trick is that there is no trick — every corner can be
defended, so the game is never about *the* answer. It is about
naming, precisely, the property your corner alone possesses.

|  |  |
| --- | --- |
| **A** — $y = x^3$ | **B** — $y = 2^x$ |
| **C** — $y = \sin x$ | **D** — $y = \frac{1}{x}$ |

> [!example]- A defence for every corner
> - **A** — the only polynomial, and the only one whose two arms
>   point opposite ways *and* run off without bound — end behaviour
>   down on the left, up on the right.
> - **B** — the only one that never dips below the axis, and the
>   only one without point symmetry: reflect A, C, or D through the
>   origin and each lands on itself; B does not.
> - **C** — the only periodic one, and the only one that is bounded:
>   every output for the rest of time lives between $-1$ and $1$.
> - **D** — the only one with a vertical asymptote, and the only one
>   that refuses an input: it has no answer at zero.

## One variation

Four *angles*: $\dfrac{\pi}{3}$ · $60^\circ$ · $\dfrac{1}{6}$ of a
revolution · $1$ radian. Three of the corners are the same angle in
different costumes — the fourth is an impostor, close enough to fool
a glance. Finding it without a calculator is [[Radian Measure]]
earning its keep.

> [!tip] "It looks different" scores nothing
> Precision is the whole game. Not "D breaks" but "D has no output
> at exactly one input, and near that input its outputs run off
> without bound". The symmetry defence of corner B is
> [[Even and Odd Functions]] in one sentence — and the wall in
> corner D is where [[Asymptotes]] begins.
