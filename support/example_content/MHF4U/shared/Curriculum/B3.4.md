solve linear and quadratic trigonometric equations, with and without graphing technology, for the domain of real values from 0 to $2\pi$, and solve related problems
*Sample problem:* Solve the following trigonometric equations for $0 \le x \le 2\pi$, and verify by graphing with technology: $2 \sin x + 1 = 0$; $2 \sin^2 x + \sin x - 1 = 0$; $\sin x = \cos 2x$; $\cos 2x = \frac{1}{2}$. ^text
