# Plantoir — instructions for agents

The instructions for this repository are in **[CLAUDE.md](CLAUDE.md)** at the
repository root: the rules that override default behaviour, the traps that cost
real time, and a map of where everything else lives. **Read that file before
doing anything here.**

Google Antigravity loads the same text without being asked. `.agents/rules/*.md`
holds a copy of CLAUDE.md, split into parts and marked `trigger: always_on` so
every part is loaded unconditionally — split because Antigravity truncates a
rule file that is too long, and one 39 KB file loses everything after its
first third without saying so.

Those parts are GENERATED. Do not edit them, and do not edit this file's copy of
anything: edit `CLAUDE.md`, then run

    python3 .agents/sync-rules.py

Machine-wide instructions (the Swift coding style) live outside this repository
— in `~/.gemini/GEMINI.md` for Antigravity, `~/.claude/CLAUDE.md` for Claude
Code. The two are kept as identical copies of each other.

**They are configured on the Mac only, and that is fine.** They govern Swift,
so a session working in `windows-app/` is not missing anything that binds it —
see rule 8, which says so in full. If you are that session and you listed your
loaded rule sets and found only `AGENTS.md` and `.agents/rules/*`, you have
everything this project asks of you.
